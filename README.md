# BAYTOUKA | بيتك — صالة المائدة والمطبخ اللبناني (The Lebanese Table)

منصة تجارة إلكترونية فاخرة (بالجملة والمفرق) مصممة خصيصاً للسوق اللبناني وقابلة لإعادة البيع والتخصيص الكامل (White-Label SaaS / E-Commerce Template) بدون لمس أي سطر برمجي.

---

## 🌟 أبرز مميزات الإصدار الثاني (Round 2 Highlights)

1. **نظام البلاطات الفنية المشرقية (Levantine Art Tiles — Zero Low-Res Photos)**:
   - إزالة جميع صور المنتجات القديمة منخفضة الدقة ونقلها إلى `/legacy-assets/products` (مستبعدة كلياً من حزمة الإنتاج `dist/`).
   - نظام رسومي متجه (36 رسمة SVG ثنائية اللون + 8 ثيمات لونية مشرقية + أقواس معمارية ونقش نحاسي) يتولد تلقائياً حسب نوع الصنف مع شارة الكود (`SKU`) ورقم الكرتونة (`Box`).
   - دعم اختياري لرفع صور عالية الدقة من لوحة الإدارة مع ضغط تلقائي إلى `WebP` وتأثير `Blur-Up`، والعودة التلقائية للبلاطة الفنية في حال عدم وجود صورة.

2. **توحيد الأصناف المتكررة في عائلات وموديلات (Product Families & Variants)**:
   - توحيد **645** سطراً خاماً في `products.json` تلقائياً إلى **265 عائلة صنف مستقلة** مع شرائح اختيار الموديلات والمقاسات (`Variant Selector Chips`) داخل نفس البطاقة.
   - تحديث فوري للسعر، الكود (`SKU`)، ورقم الكرتونة (`Box`) عند النقر على أي موديل دون إعادة تحميل الصفحة.

3. **5 باقات جاهزة للعرائس والمتاجر + مصمم الباقة التفاعلي من 5 خطوات**:
   - 5 باقات جاهزة (`Essential`, `Classic`, `Premium`, `Royal`, `Wholesale Shop Starter`) مبنية من أصناف الكتالوج الحقيقية.
   - أداة تفاعلية من 5 خطوات حسب غرف وأقسام البيت مع حلقة إنجاز (`Progress Ring`) وحساب فوري للتوفير.

4. **لوحة إدارة متكاملة + ربط Supabase + تخصيص White-Label كامل (`#/admin`)**:
   - **صفر بيانات مبيعات وهمية**: يبدأ المتجر بـ `0` طلبيات و `$0.00` مبيعات وأرباح.
   - **تسجيل الطلبيات الحقيقية فقط**: لا تُسجّل الطلبية إلا عند ضغط الزبون على زر **«إتمام الطلب عبر واتساب»** في السلة مع التحقق من الأسعار وتوليد رقم طلبية رسمي (`BYT-YYYYMMDD-XXXX`).
   - **محلي أو سحابي (Supabase)**: يعمل فوراً بدون إعدادات، أو يرتبط بمشروع Supabase مجاني لمزامنة الطلبيات والمنتجات والإعدادات بين جميع الأجهزة.

## 🚀 التشغيل السريع (Quick Start)

1. **التشغيل المباشر بدون خادم (`file://`)**:
   - افتح `index.html` أو `dist/index.html` مباشرةً بالنقر المزدوج في أي متصفح.
2. **التشغيل عبر بيئة التطوير (Node.js / Vite)**:
   ```bash
   npm install
   npm run dev      # خادم التطوير المحلي
   npm run build    # بناء حزمة الإنتاج في dist/ وتحديث js/app.bundle.js
   ```

## 🗄️ إعداد قاعدة بيانات Supabase المجانية (10 دقائق — خطوة بخطوة)

1. أنشئ حساباً مجانياً على [supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً (**New Project**).
2. من القائمة الجانبية، افتح **SQL Editor** ثم انسخ محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) بالكامل واضغط **Run**:
   - يقوم هذا الملف بإنشاء الجداول (`products`, `categories`, `packages`, `orders`, `order_items`, `settings`)، تفعيل سياسات الحماية (`Row Level Security`)، وإنشاء دالة التحقق من الأسعار `submit_customer_order`، وحاوية الصور `product-images`.
3. **(اختياري) رفع الـ 645 صنفاً إلى قاعدة البيانات**:
   - شغّل الأمر `node supabase/seed.mjs` لتوليد ملف `supabase/seed-products.sql` أو انسخه مباشرةً إلى **SQL Editor** واضغط **Run**.
4. **إنشاء حساب المدير (Admin User)**:
   - من لوحة Supabase اذهب إلى **Authentication → Users → Add User → Create New User** وأدخل بريدك الإلكتروني وكلمة المرور.
5. **ربط المتجر بـ Supabase**:
   - انسخ `Project URL` و `anon public key` من **Project Settings → API**.
   - يمكنك وضعهما في ملف `.env` (بناءً على `.env.example`) أو إدخالهما مباشرةً بدون كود من داخل الموقع عبر `#/admin` ← تبويب **إعدادات المتجر والربط**.

## ⚡ دليل المالك: كيف تضيف صنفاً جديداً في 30 ثانية؟ (Add a Product in 30 Seconds)

1. افتح لوحة الإدارة بالضغط على زر القفل **«لوحة الإدارة»** في أعلى أو أسفل الموقع (`#/admin`) وسجّل الدخول.
2. انتقل إلى تبويب **«المنتجات والموديلات»** واضغط زر **«+ إضافة صنف أو موديل جديد»**.
3. املأ الحقول الأساسية:
   - **اسم الصنف بالعربية** (مثال: `طقم طناجر غرانيت تركي`).
   - **كود الموديل (`SKU`)** ورقم الكرتونة (`Box`) والمقاس (`10PCS`).
   - **سعر الجملة** و**سعر المفرق** بالدولار.
   - *(اختياري)* ارفع صورة للمنتج ليتم ضغطها تلقائياً بصيغة `WebP`، أو اتركها فارغة ليقوم النظام بتوليد بلاطة فنية مشرقية (`Art Tile`) تلقائياً!
4. اضغط **«حفظ الصنف وتحديث الكتالوج»** — سيظهر الصنف فوراً في صالة العرض!

## 🏷️ قائمة تسليم الموقع لمشتري جديد (White-Label Buyer Handover Checklist)

عند بيع هذا الموقع لصاحب متجر جديد، يمكن للمشتري تخصيص المتجر بالكامل من تبويب **«إعدادات المتجر (White-Label)»** في `#/admin` خلال دقائق بدون تعديل أي كود:

- [ ] **تغيير اسم المتجر** بالعربية والإنجليزية والوصف الترويجي (`Tagline`).
- [ ] **تغيير رقم واتساب للطلبيات** (`961XXXXXXXX`) وروابط إنستغرام وفيسبوك والعنوان وساعات العمل.
- [ ] **اختيار الهوية اللونية (Color Preset)** من بين 5 ثيمات لونية جاهزة (`المائدة اللبنانية`, `الأرز والذهب`, `البحر المتوسط`, `الورد الدمشقي`, `السبائك الملكية`).
- [ ] **تعديل حد التوصيل المجاني** للمفرق والجملة ونسبة خصم الكميات (`12+` قطعة).
- [ ] **تعديل أسعار التوصيل للمحافظات اللبنانية** والأسئلة الشائعة (`FAQ`) وشريط الإعلانات العلوي.
- [ ] **تعديل أو استبدال الأصناف** عبر الإدخال المباشر أو استيراد ملف Excel/CSV أو JSON بضغطة زر.
